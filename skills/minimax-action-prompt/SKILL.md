# MiniMax H3 武戏提示词技能

## 使用范围与优先级

用于战斗、追逐、搏斗、兵器交锋、能力对抗和大幅动作场景。它是当前系统的通用武戏主规则；二次元打戏技能只在动漫/二次元风格下作为风格增强，不重复覆盖本技能。规则优先级为：

1. 用户明确指定的角色、装备、能力、动作、时长、胜负和时间点；
2. 参考图真实可见的外形、装备、武器、能力和场景；
3. 已确认角色的战斗习惯；
4. 为保证动作连续性所需的最小补全；
5. 导演原创。

用户要求与参考图冲突时遵循用户明确要求；没有明确要求时保持参考图事实。完整模板见 `references/minimax_action_template.txt`。

## 资产事实锁定

- 参考图作为首帧时，必须从图中已有姿态、重心、朝向、景别和持有状态内部启动动作，不能第一帧换姿势、武器或构图。
- 角色参考图只锁定脸、发型、体型、肤色、配饰和可见装备；本镜服装与配色以分镜 wardrobe 和剧情状态为准，场景参考图锁定建筑、材质、光源、天气和空间关系。
- 参考图没有武器且用户未指定时，角色始终徒手；不得因“剑神、刺客、战士”等称号自动补武器。
- 超自然能力只在用户明确指定、参考图清楚显示或当前已确认角色设定明确具备时使用。能力必须从真实身体部位、武器、机械结构或已有介质触发。
- 不添加第三名战斗角色；不让武器无因变形、消失、复制、换手或改变尺寸；不让双方的脸、服装、装备、能力颜色和特效规律互相混合。

## 战斗载体

动作必须匹配真实载体：

- 刃器：斩、刺、挑、格、拨、压、绕和贯穿，写清刃线、火花、裂口和目标偏转。
- 长柄武器：利用距离、中线、压杆、横扫、枪尾/柄部短打和转向惯性。
- 钝器：砸、压、推、撞、抡和震击，表现凹陷、碎裂、击退和结构受力。
- 远程武器：保持瞄准、发射、弹道、遮挡、规避、拦截和间隔清楚。
- 徒手：拳、掌、肘、膝、腿、肩撞、擒拿、卸力、翻摔、贴身闪避和环境借力；双手保持空置。
- 生物、飞行生物、机械和载具：只使用真实可见的肢体、翅膀、足数、推进器、轮组、机械臂、炮口、装甲和关节。

双方交锋必须按条件适配。徒手角色不能无依据硬接锋刃；双方都徒手时不得出现刀光、剑气、枪影或金属撞击；双方都使用能力时，围绕接触、偏转、束缚、压缩和环境传播设计，禁止两团光远处对轰。

## 动作因果链

0 秒立即进入有效动作，不写开场对峙、凝视、摆姿势、环境空镜或慢速入场。每个重要动作完整写出：

`起势预兆 → 身体/装备/能力加速 → 攻击路线 → 接触点 → 防御/闪避/反制 → 受力与形变 → 位移 → 环境反馈 → 下一招`

每次交锋至少改变位置、方向、高度、速度、姿态、攻守关系、环境结构或能力状态中的一项。双方不能长期原地互殴，不能只写“命中、爆炸、冲击波”而省略受击者的失衡、后撤、翻滚、撞击或战斗状态变化。

## 15 秒动作结构

系统当前镜头时长为 `8~15 秒`。模板默认的 15 秒结构可压缩到实际时长：

- 0~3 秒：零前摇开战，完成第一组攻防和首次接触；
- 3~6 秒：改变高度、地形或空间轴线，完成明确命中或强制位移；
- 6~10 秒：中近景技术交换，形成第一次攻守逆转；
- 10~13 秒：追杀、封锁、绕后或环境折返，建立终结线路；
- 13~15 秒：三拍终结，明确胜者、败者状态和最终落点。

8~12 秒镜头应合并相邻阶段，但仍保留“开战 → 接触 → 状态变化 → 结果/悬念”的完整因果链。若用户没有指定胜负，则以本镜头目标或上一镜状态为依据，不能无故改变既定结果。

## 镜头、连续性与反馈

- 每次切镜只改变观察角度，不重置动作。下一镜至少继承双方位置、朝向、速度/方向、高度、装备/能力状态、受击状态、碎片/尘雾/裂纹/余波中的四项。
- 镜头职责随动作变化：贴地或斜侧追拍开战，仰角升镜展示空间变化，侧后方近景看技术交换，高速跟随呈现封锁和绕后，最后拉开或稳定展示终结结果。
- 摄影机可以制动，但主体、衣料、碎屑、尘雾、流体或残余能量至少有一项持续运动；当前系统禁止慢动作、升格、子弹时间、定格和全画面冻结。
- 命中、格挡、冲撞和能力接触必须表现身体/装备受力、脚底摩擦、衣料发丝延迟、碎屑尘雾和沿受力方向的位移。
- 环境破坏遵循材质和方向：横向攻击横断，下劈向下塌陷，穿刺沿贯穿方向裂开，撞墙裂纹从接触点扩散，滑行留下连续摩擦痕。
- 不用大面积光效、烟雾或爆炸遮挡核心攻防；能量颜色、形状、来源和所属角色保持稳定。

## 输出约束

适配当前 MiniMax H3 提示词格式和系统 `8~15 秒` 时长规则，不输出原模板中的 `BUNNY` 前缀，不固定写死 15 秒，不输出未替换的方括号占位内容。

最终提示词只交付成品，不输出分析或识别报告。默认用简体中文，包含：

1. 时长、画风、场景、角色身份、参考图锁定、战斗载体和能力规则；
2. 按时间推进的连续动作与镜头；
3. 明确声音来源：脚步、破风、真实材质接触、身体受力、环境破坏和余波；
4. 明确胜负、败者状态、最终落点和最后一帧的环境运动。

没有明确对白时不新增对白、旁白、字幕或可读文字；没有金属接触时不写剑鸣或金属撞击声。

## 输出前检查

1. 每个武器和能力都有用户或参考图依据，无武器角色全程徒手。
2. 首帧即运动，动作有起势、线路、接触、受力、位移和后续结果。
3. 五个时间阶段或压缩后的等价结构动作连续，没有重复招式、构图、运镜和受力方向。
4. 每次切镜继承至少四项状态，角色脸、服装、装备和身体结构稳定。
5. 环境破坏符合材质和受力方向，特效不遮挡攻防。
6. 终局胜负明确，最后一秒不突然增加新武器、新招式、新形态或新能力。

## 剧情服装与身份连续性

- 将本镜 `wardrobe` 中各角色的款式、颜色、鞋子、穿脱及污损状态明确写入最终提示词；参考图锁定身份，不能覆盖本镜服装。
- 同一场连续戏保持着装连续；换天、换活动或明确换装时合理变化，不能为丰富画面逐镜换衣。保持战斗造成的破损、污渍等剧情状态。
- 不同角色按身份、性格区分着装；制服场景允许相同制服。按年代和明确剧情安排睡眠、居家、职业及正式着装，不把全剧角色锁在同一套基础造型里。
- 输出前检查服装计划是否逐人落实；合理换装不属于角色身份漂移。
