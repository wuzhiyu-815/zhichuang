# 二次元打戏提示词技能

## 目标

把“两个角色激烈战斗”改写成可拍摄、可生成、能继续推进叙事的动作链。每次输出都要让模型知道：

- 谁在进攻，谁在防守，攻防为什么发生变化；
- 每一击的招式、攻击部位、运动方向、命中反馈和下一步衔接；
- 角色各自的动作签名、特效主色和胜负趋势；
- 镜头看什么、从哪个方向看、如何运动、为什么切换。

## 系统适配

- 当前视频时长以系统传入的 `8~15秒` 为准，禁止写死为15秒。
- 遵循系统的禁止慢放和禁止冻结规则，不使用“慢动作、升格、子弹时间、slow motion、定格”等表述。需要节奏反差时使用“短促节拍后立即加速”“命中瞬间清晰强调接触反馈”等可执行描述。
- 当前生成器是 MiniMax H3，最终输出必须遵守 H3 三字段格式、`<Picture N>`、`<d>[Chinese]... </d>` 和 `The camera` 运镜句式。
- 不把 Seedance 的品牌名称、专属 JSON 或固定 15 秒模板写进最终 H3 提示词。

## 动作编排

### 开场

首帧就有动作，避免站立摆拍和空镜铺垫。动作冲突应尽早发生：突进、截击、格挡碰撞、闪身绕背或大幅位移至少选择一种。

### 攻防链

使用“起势 → 发力 → 目标 → 命中/落空 → 身体反馈 → 下一招”的连续链。每个动作都要改变局势，禁止只写“快速连击”“打得很激烈”。

近身对招优先写清楚招式链，例如：

`右直拳打面门 → 前臂格挡弹开 → 左摆拳扫肋 → 下潜避开 → 右横肘切入肩颈`

小幅手部动作使用近景或中近景；腾空、旋转、扫腿、摔投和大幅位移使用中景或全景。动作完成后要紧接追击、反制或位置变化，不能在抓住、摔倒或格挡后停住。

### 节奏

在传入时长内安排“冲突开场 → 密集对招 → 空间变化 → 情绪拐点 → 终结或悬念收束”。快慢变化通过动作密度、切镜和短暂停顿表达，不写抽象频率参数，不写“每秒攻击几次”。

至少加入一种空间变化：贴地、腾空、翻转、绕背、墙面借力或大幅横移。终结技要写清破防原因、命中部位和环境反馈；如果本镜不是终结镜，则保留合理的未完成状态。

## 镜头规格

每段镜头描述尽量完整包含：

`景别 · 视角/角度 · 运镜方式 · 跟随目标`

推荐写法：

- 近景 · 侧面90°平视 · 跟拍跟镜 · 跟随双方前臂攻防；
- 中景 · 45°斜拍平视 · 急速推镜 · 跟随攻击方拳面；
- 全景 · 30°仰视 · 升降运镜 · 跟随腾空身体和落地轨迹；
- 特写 · 正面微侧平视 · 急速推镜 · 推进至拳面与目标的接触点。

运镜必须有动机：跟随攻击方向、展示空间变化、锁定破绽、放大命中反馈或交代双方位置。中景/全景优先用斜角制造纵深；环绕只用于短距离、最多半圈的对峙或位置变化，避免无意义旋转。

## 特效与环境反馈

特效必须绑定身体部位和运动路径，不写成漂浮装饰：

`起源点 → 流动轨迹 → 命中爆散 → 余韵残留`

示例：

`紫黑气焰从右小腿浮现，沿旋踢弧线拉出细锐弧刃，命中护臂时压缩成环形气爆，地面尘土向外推开。`

每次重击至少提供一种可见反馈：衣物和发丝受力、汗水或碎屑飞散、脚下尘土、墙面裂纹、冲击波、受击者后仰或失去重心。轻击也要有较轻的拳风、空气波纹或格挡震颤。

## 角色与特效

为每个角色保留稳定的动作签名和视觉主色。角色改变时可以复用招式；同一对战组合的新版提示词应避免重复完全相同的招式链。

常用视觉性格：

- 火焰：由拳面、肘尖或膝盖爆发，重击带热浪和碎屑；
- 雷电：电弧沿出招路径瞬闪，残痕短促，不覆盖全部画面；
- 霜雾：寒气从接触点弥漫，强调渗透和薄霜；
- 花瓣/粉色气焰：轻击飘散，重击颜色加深，终结形成旋舞风暴；
- 黑白劲气：围绕掌、拳和身体轴线旋转，体现化劲与借力。

如果用户没有指定特效，不要强行套用固定角色颜色，应从画风、场景和角色性格推导一组互补色。

## 输出前检查

1. 首帧是否正在运动，是否尽早发生冲突。
2. 是否至少有一段近景/中近景攻防和一段空间变化。
3. 是否逐击写了落点、格挡/闪避反馈和后续动作。
4. 是否根据动作幅度匹配景别，并写清视角、角度、运镜和跟随目标。
5. 特效是否绑定部位和轨迹，环境是否有反馈。
6. 是否明确本镜的局势变化、情绪拐点或收束目的。
7. 是否遵守当前 H3 格式、时长规则、台词规则和禁止慢放规则。

完整的原始资料保存在 `references/original_skill.md`，只有需要查询具体技法库、角色模板或场景清单时才读取。

## 剧情服装与身份连续性

- 将本镜 `wardrobe` 中各角色的款式、颜色、鞋子、穿脱及污损状态明确写入最终提示词；参考图锁定身份，不能覆盖本镜服装。
- 同一场连续戏保持着装连续；换天、换活动或明确换装时合理变化，不能为丰富画面逐镜换衣。保持战斗造成的破损、污渍等剧情状态。
- 不同角色按身份、性格区分着装；制服场景允许相同制服。按年代和明确剧情安排睡眠、居家、职业及正式着装，不把全剧角色锁在同一套基础造型里。
- 输出前检查服装计划是否逐人落实；合理换装不属于角色身份漂移。
