# 图片文字提取

## 用途

把用户上传的图片内容转换成可编辑文字。适用于故事梗概长图、聊天截图、扫描文档、漫画对白、收据和界面截图。

## 工作规则

1. 先完整查看图片的方向、语言、分栏、段落和边缘内容。
2. 按自然阅读顺序提取文字。长图必须从上到下分段读取，不能跳段、漏段或重复。
3. 保留原图中有意义的标题、段落、列表、对白、标点、数字和专有名词。
4. 不凭上下文猜测看不清的字。看不清的内容使用 `[不清]`、`[?]` 或 `□` 标记。
5. 只做文字提取，不自动总结、翻译、改写或生成剧本。
6. 提取结果回填故事梗概后，必须由用户检查和编辑，再进入 AI 导演台匹配。

## 质量检查

- 阅读顺序从上到下，没有跳过图片中间区域。
- 段落和对白边界尽量与原图一致。
- 人名、数字、标点和重复内容已复核。
- 不清晰内容已明确标记，没有擅自补字。
