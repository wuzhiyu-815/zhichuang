Windows 剪映专业版草稿包

1. 将 ZIP 完整解压到本地文件夹，不要在压缩包中直接运行。
2. 在剪映「全局设置」中查看「草稿位置」，然后退出剪映。
3. 双击 import.cmd，选择上述草稿根目录。工具会新建一个草稿文件夹、复制素材并修正本地素材路径，不覆盖已有草稿。无需安装 Python。
4. 重新打开剪映，在本地草稿列表中打开本次导入的剧名。

时间线按集数、镜头顺序排列，原视频和原声完整保留，不重新编码。
“按镜头”导出保留独立剪辑点；“按整集”导出每集是一段成片，成片中烧录的字幕不可单独编辑。
如果选择“可编辑对白字幕”，字幕会单独放在文本轨道。其时间按镜头内对白均分估算，不是语音识别结果，请在剪映中校对。
原声仍嵌在视频里，可在剪映中分离音频；没有独立录音的数据不能拆成独立人声、音乐轨道。
浏览器只负责下载，无法替你直接写入本地剪映目录。

兼容说明：此包由 pyJianYingDraft 0.3.0 生成，面向 Windows 剪映专业版，非 CapCut。
本项目验证了草稿结构、素材引用和时间线；具体剪映版本的打开效果仍需在本机确认。
若草稿未出现，请核实所选目录与剪映设置一致，并重启剪映。
不要单独移动导入后的 media 文件夹；素材路径指向已导入的草稿目录。
