ComfyUI 节点管理

      

        

        
每台节点可单独启用或停用；停用只会停止任务分发，不会关闭其他节点或远程服务器进程。

        

        
所有启用且在线的节点都会参与任务分发；系统优先使用空闲节点，并轮流分配任务；有前后依赖的镜头需等待前置镜头完成。

      

    

    
  







  

    
⚙️ API 与生成设置

    

      

        
        
      

      

      
模型 API 按账号独立保存；普通成员的 ComfyUI 节点由管理员分配。生成任务使用项目所属用户的配置。
