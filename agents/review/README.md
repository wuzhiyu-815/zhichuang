# 审片智能体

## 职责

通过视频关键帧和视觉模型检查生成质量。

## 检查项目

角色一致性、动作连续性、构图运镜、场景连续性、物体细节和台词匹配。

## 输出

评分、问题列表、问题分类和修复建议。

## 服装职责

将生成视频与本镜 wardrobe 对比，检查服装是否符合剧情及镜内连续性；合理换装不算角色漂移。发现着装不合场景时，写出正确服装的修复约束。


## 镜头交接规则（第11集实测后更新）

智能体流程默认启用 continuity_enabled；项目 render_config 可设 false 关闭。分镜阶段规划 start/end 与 opening/continuous/cut，连续镜必须继承前镜尾态，时空转场明确理由。固定空间地标、姿势、朝向、左右手、服装、持物数量、包装和遮盖状态，状态改变必须有可见过渡，不重复已完成动作。

提示词阶段结合实际末帧预审，逐字保留台词顺序和说话人；身份介绍不朗读。渲染连续镜必须等待前镜完成，保留角色/场景/道具参考并追加实际末帧为辅助参考，最多8张原参考加1张末帧；不得为塞入末帧丢弃身份或道具图。换机位保持世界坐标，换场或时间跳转不追加末帧。当前使用R2V辅助参考，不承诺等同I2V硬首帧锁定。

渲染后保存相邻首尾帧报告于 continuity_reviews，遮挡或模型输出异常记uncertain，报告均待复核，不因画面左右变化、不可见物品或后镜尚未完成的动作自动重渲染。上一镜重生成后，连续的下一镜标记continuity_stale并在续跑时重做。历史成片不批量覆盖。


## 3D动画风格继承（第12集对照后）

3D动漫/国漫项目统一人物、场景、道具的动画建模与材质描述，保留既有身份和项目美术比例，不强制改为欧美卡通。生图扩写与最终视频提交均追加3D媒介约束。

智能体渲染默认先按原参考图及交接状态规划完整镜头首帧，再生图并做身份、年龄、服装、画风、空间、道具数量检查。检查失败修正一次，仍失败则保留候选和JSON报告并报错；不因动画感强就放行。当前首帧采用视觉理解后文字生图，不是图像身份硬锁，自动检查也非人工验收保证。通过后使用H3 I2V；原身份参考用于首帧规划和审查，不作为I2V额外输入。

项目render_config.style_first_frame_enabled=false或镜头style_render_mode=r2v可保留R2V；非3D项目、即梦提供商及有参考音色的镜头保留原路径。I2V使用自身FL2VA权重与调度器，不宣称与R2V同模型。

首帧候选与报告保存于输出目录first-frame-*.json，实际模式与来源记录在镜头style_render；修改提示词、镜头或参考图后缓存失效。旧成片不自动替换。风格和身份以实际视频复核为准，大动作/复杂换机位不能凭文戏测试直接判为稳定。

## 听音质检（2026-09-20）
每个项目镜头生成后调用8101转写和8102盲听质检，报告保存在镜头audio_review和reviews/audio目录。
实际台词独立对比剧本，忽略标点和空白，保留重复、增删字差异；ASR差异仅标待复核，不自动判定漏词或自动重制。
8102 pass不代表台词正确、响度合规或说话人身份正确。人数不匹配、峰值风险和模型问题须复核；空字段、接口失败、无音轨或测量错误不得判通过。
音频超过25秒自动切片并按实际片段时长累计偏移；start/end分别处理null。多个片段的人数不能相加推断全片说话人数。
服务串行调用，502最多重试一次，连接8秒/响应120秒超时；报告按文件变更及剧本、服务地址缓存，未完成检查允许重试。
听音未通过时总审片不能标通过，但不据听音报告自动重制。界面显示期望台词、实际转写、指标及问题供人工判断。
