# 资产智能体

## 职责

管理角色、场景、道具参考图，处理上传图片和历史资产复用。

## 输入

剧本资产描述、画风、用户上传图片和历史项目资产。

## 输出

资产文件、资产提示词、图片分析描述和资产状态。

## 服装职责

角色参考图用于身份识别，图中服装只是一套基础造型，不作为全剧制服。不因换装创建新的角色身份。


## 3D动画风格继承（第12集对照后）

3D动漫/国漫项目统一人物、场景、道具的动画建模与材质描述，保留既有身份和项目美术比例，不强制改为欧美卡通。生图扩写与最终视频提交均追加3D媒介约束。

智能体渲染默认先按原参考图及交接状态规划完整镜头首帧，再生图并做身份、年龄、服装、画风、空间、道具数量检查。检查失败修正一次，仍失败则保留候选和JSON报告并报错；不因动画感强就放行。当前首帧采用视觉理解后文字生图，不是图像身份硬锁，自动检查也非人工验收保证。通过后使用H3 I2V；原身份参考用于首帧规划和审查，不作为I2V额外输入。

项目render_config.style_first_frame_enabled=false或镜头style_render_mode=r2v可保留R2V；非3D项目、即梦提供商及有参考音色的镜头保留原路径。I2V使用自身FL2VA权重与调度器，不宣称与R2V同模型。

首帧候选与报告保存于输出目录first-frame-*.json，实际模式与来源记录在镜头style_render；修改提示词、镜头或参考图后缓存失效。旧成片不自动替换。风格和身份以实际视频复核为准，大动作/复杂换机位不能凭文戏测试直接判为稳定。
