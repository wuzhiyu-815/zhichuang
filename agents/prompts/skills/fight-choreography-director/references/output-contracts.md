# 输出契约

## 阶段一：战斗设计方案

默认先输出以下内容并等待用户确认：

1. **理解与默认值**：题材、人物、武器或能力、场景、时长、画幅、帧率、平台、开场、结局和非血腥等级。
2. **战斗逻辑**：双方目标、优势、短板、胜负条件和环境机会。
3. **时间轴攻防节点**：每段标明起止时间、攻击、化解、有效反击、位移、反馈和镜头。
4. **节奏与终结**：密度变化、局势升级、速度变化和最终画面状态。
5. **连续性风险**：惯用手、武器、位置、伤势、服装、能力代价和环境破坏。

结尾用一句简短问题邀请用户确认或指出修改点，不追加完整提示词。

## 阶段二：完整提示词

用户确认后输出：

1. **可复制的通用视频提示词**：完整自然语言，包含时间、动作、摄影、物理、声音、情绪和终结状态。
2. **负面约束**：集中列出站桩、回合制停顿、肢体错误、武器变形、身份漂移、无故换装、空间跳跃等风险。
3. **平台适配版**：仅在用户指定 Seedance、Kling 或 Runway 时追加。

不要重复阶段一的长篇解释。

## “直接生成”模式

用户说“直接生成”“不用确认”“一次给完”或同义表达时，一次输出：

1. 精简动作纲要，篇幅不超过总输出约 20%。
2. 可复制的完整通用提示词。
3. 负面约束。
4. 已指定平台的适配版。

## 审查与修正模式

用户给出已有提示词或生成结果时：

- 先识别失败类型：攻防逻辑、动作密度、物理反馈、空间连续、角色一致、武器一致、镜头可读性、速度变化或平台组织。
- 保留用户已经满意的部分，只修改造成失败的最小范围。
- 明确指出修改前后最关键的差异，然后给出可直接替换的版本。
- 若输入是现实伤人咨询，转为非血腥虚构表演、安全训练或镜头设计，不输出可执行伤害步骤。
