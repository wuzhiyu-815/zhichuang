# 03 叙事与选题规则

> 来源：用户提供的 `D:\导演\知识库\03-叙事与选题规则.md`，收录日期 2026-09-26。以下保留原始商业短剧经验；应用边界由上级 SKILL.md 规定。题材热度并非实时核验数据，“所有创作”“必须爽”“无洗白空间”等表述只适用于选定的直接爽剧模式，不覆盖用户指定题材、人物灰度、结局或改稿范围。

前缀 `STR-`。用于选题、定方向、写剧本、分集规划。

## 一、平台策略

### [STR-01] 平台 → 时长与题材
- 适用场景：立项定方向
- 规则：

| 平台 | 单集时长 | 主打 | 题材 |
|---|---|---|---|
| 抖音/快手 | 1–2 分钟 | 强冲突、强视觉 | 虐渣、逆袭 |
| 视频号 | 1–3 分钟 | 情感共鸣、清爽感 | 甜宠、家庭逆袭 |
| 小红书 | 30 秒–1 分钟 | 颜值向、轻量化 | 截精彩片段做人设引流 |
| B站 | 2–5 分钟 | 内容深度 | 悬疑、奇幻、治愈 |

- 来源：P09

### [STR-02] 新手起步组合
- 适用场景：首次做号
- 规则：优先抖音/快手 + 逆袭类或虐渣类
- 反例：避开文艺类、现实类等小众题材
- 来源：P09

## 二、题材与情绪

### [STR-03] 题材优先级
- 适用场景：选题决策
- 规则：

| 题材 | 说明 |
|---|---|
| 逆袭类 | **最热**。废柴逆袭、豪门妻女、赘婿崛起、职场逆袭 |
| 虐渣类 | 婚内出轨、闺蜜背叛、家人偏心、主角反击 |
| 甜宠类 | 霸总护妻、先婚后爱、穿越甜宠，**适合新手** |
| 悬疑类 | 反转、密室逃脱、凶案推理，**难度高** |
| 穿越重生/异能修仙 | **适合 AI**，省特效成本 |

- 来源：P09

### [STR-04] 四大核心情绪
- 适用场景：单集情绪设计
- 规则：爽、怒、甜、疑。**一集只主打一到两种**，煽情点到为止
- 来源：P09

### [STR-05] 核心理念
- 适用场景：所有创作决策
- 规则：低成本、高产出、高转化；主打"即时爽感"，拒绝复杂铺垫；不拖沓、不模糊人设、不烂尾
- 来源：P09

## 三、结构设计

### [STR-06] 整体结构
- 适用场景：多集规划
- 规则：主线明确 + 每集小冲突 + 中期大反转 + 圆满结局
- 来源：P09

### [STR-07] 单集结构
- 适用场景：单集剧本
- 规则：钩子开头 → 冲突升级 → 小反转/小爽点 → 结尾留钩子
- 判优标准：开头有没有钩子、中间有没有反转、结尾有没有给下一集埋钩子
- 来源：P09 / P10

### [STR-08] 单集时间轴（2 分钟）
- 适用场景：控制节奏
- 规则：

| 时间 | 内容 |
|---|---|
| 0–3 秒 | 抛钩子，直接抛冲突（例："离婚吧，你就是个废物"） |
| 3–30 秒 | 冲突升级 |
| 30–90 秒 | 爆发爽点 / 小反转 |
| 收尾 | 留钩子 |

- 补充：每 15–20 秒制造一个小爽点或小冲突
- 来源：P09

## 四、人物设定

### [STR-09] 人设三原则
- 适用场景：角色设计
- 规则：
  - **主角**：人设鲜明、目标明确
  - **反派**：坏得直白、**无洗白空间**（贪婪、恶毒、偏心），不留道德灰色地带
  - **配角**：纯工具人，不做复杂人设
- 反例：反派留灰色地带 → 人物站不住；配角有复杂动机 → 观众产生多余联想
- 来源：P09 / P10

### [STR-10] 金句
- 规则："短剧讲究的就是简单爽……不要让观众诞生多余的想法。"
- 来源：P10

## 五、台词与视听配合

### [STR-11] 台词风格
- 适用场景：剧本对白
- 规则：大白话、有张力、不弯绕
- 来源：P09

### [STR-12] 镜头与音效配合情绪
- 适用场景：分镜与剪辑
- 规则：冲突 = 近景 + 快切；甜宠 = 慢镜头 + 柔光。音效：打脸 = 重低音，甜宠 = 轻柔 BGM，悬疑 = 紧张声响
- 来源：P09

---

## 六、避坑

### [STR-13] 常见坑
- 适用场景：剧本终审
- 规则：
  1. 不烂尾，结局必须爽
  2. 反转要合理，并**提前埋伏笔**
  3. 同一冲突不重复
  4. 每集必须推进主线
- 来源：P09

### [STR-14] 可行性规避（AI 生成视角）
- 适用场景：写分镜脚本时同步考虑
- 规则：主动规避——人数多的画面（人物崩坏、对口型识别不出正确人物）、激烈打斗、运镜转场复杂的画面
- 来源：P10
