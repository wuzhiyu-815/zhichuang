# 攻防编排引擎

## 核心单位

- **有效战斗时长**：总时长减去纯开场、纯收尾、蓄力、升格停留和必要转场。
- **攻防链**：攻击 → 化解/闪避/格挡 → 反击 → 再次处理。一次攻防链可以在一个连续动作里完成，不等于轮流出招。
- **权力转移**：谁控制距离、中线、节奏或空间。每一阶段都要说明控制权为何改变。
- **可见反馈**：重心、脚步、惯性、呼吸、衣料、武器、环境或声音中至少两项明确回应动作。

## 设计顺序

1. 为每位参战者写一句战斗目标、优势、短板和标志性动作语言。
2. 先分配时间：建立距离、第一次交锋、升级、反转、终结、余波。短片可以合并相邻阶段，但不能让开场和结尾吞掉主要战斗。
3. 选择动作密度，再写动作。动作密度是可读性预算，不是数字竞赛。
4. 逐节点写“动作—应对—反击—结果”，并让结果改变距离、方位、武器状态、环境或情绪。
5. 检查双方主动性和连续性；删掉摆姿势、无因停顿、重复后跳及只有攻击没有应对的描述。

## 动态密度

把下列范围当作起点，不是硬性指标：

- 快速徒手、短兵器贴身战：每 2 秒约 3–4 次清晰攻防转换。
- 标准刀剑、棍枪或中等重量战斗：每 2 秒约 2–3 次转换。
- 重武器、重甲、机甲、巨兽：每 2 秒约 1–2 次主转换，同时写清启动、蓄力、惯性和余震。
- 法术、超级能力或远近结合：将蓄力、释放、拦截、改向、贴近和反击分别计时，不用光效替代攻防逻辑。
- 升格时刻：按真实时间占用计算，减少同一时间段内的招式数。

若动作读不清，先减少同时事件，再调整镜头；不要通过无限增加文字掩盖时间不足。若有效战斗时间有冗余，增加有因果的攻防转换或环境位移，不要加入慢动作和站立停顿凑时长。

## 连续动作原则

- 每次攻击说明发力来源和路线，但保持影视表达，不写现实伤害教学。
- 防守不能只写“挡住”：说明化解方式、付出的代价及如何形成反击窗口。
- 受击者必须有重量反馈；胜者也要受惯性、落点和恢复动作影响。
- 长武器保持距离优势，短兵器通过切角和贴近解决距离；重武器的回收更慢；软兵器必须表现路径和张力。
- 终结动作必须由前一阶段制造的失衡、缴械、空间限制、能力消耗或情绪失控导致。

## 人数变化

- 一对多：给主角明确移动路线，把敌人分成前、中、后威胁层；每次只突出一个主攻者，其他人通过包围、逼位或拦截参与。
- 多对多：建立两到三个视觉锚点，按局部小组编排并用共同环境事件连接，避免所有人同时执行不同招式。
- 巨型单位：把肢体或装备当作移动环境，强调尺度、延迟和冲击传播。

## 通过条件

- 时间段连续、无重叠、总和正确。
- 双方至少各有一次主动进攻和一次改变局势的有效应对，除非用户明确要求一边倒。
- 每个阶段都改变至少一个状态：距离、方位、武器、体力、环境、情绪或控制权。
- 开场、升级、反转和结局可以被观众只看动作就理解。
