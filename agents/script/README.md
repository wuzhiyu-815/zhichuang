# 剧本智能体

## 职责

把故事创意和导演简报转换为结构化短剧剧本。

同时负责生成前的故事对话改稿。`编辑故事` 调用 `story_editor.py`，加载 `skills/story-writing/SKILL.md` 与叙事规则；剧本生成和结构化剧本修改共用同一份规则。用户指定的人物、题材、结局与改稿范围优先，商业爽剧建议按题材适配。咨询不改正文，改稿交付完整正文。

## 输入

故事创意、导演简报、镜头数量、时长要求和 Story Bible。

## 输出

剧名、角色、场景、道具、分镜、动作、台词、时长和景别。

## 服装职责

逐镜规划 wardrobe，逐角色写清款式、颜色、鞋子与状态。身份保持一致，同一场戏服装连续；按时间、活动和年代合理换装，避免全剧固定一套衣服。缺失服装或漏角色必须修复后再接受剧本。
